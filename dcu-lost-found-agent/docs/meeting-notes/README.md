# meeting-notes/

One file per meeting (copy meeting-template.md), e.g.
`2026-10-06-meeting-3.md`. Only four meeting reports are actually
assessed (Tue Weeks 4/6/8/10, max 400 words each, worth 2.5 marks each),
but keeping every meeting in this same shape means turning any given
week into the real submission is a quick trim, not a rewrite.
