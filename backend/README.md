# backend/

The Django project — the actual web app. Once `django-admin startproject`
has been run, the standard Django layout (manage.py, the project settings
package) lands here, alongside the apps below.

If the group goes with plain HTML/CSS/Bootstrap instead of React,
templates and static files also live here (standard Django convention:
`items/templates/`, `items/static/`) and `frontend/` can be deleted.
